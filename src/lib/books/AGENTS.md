# Books, tax and compliance rules
- Company/person profiles (src/lib/entities.ts) live in owner preferences.entities; PAN type letter and GSTIN embedded PAN/mod-36 check are validated before save, and financial-year status is counted from saved records only, never marked complete automatically.
- Supplier/missing-invoice checks (src/lib/gst-recon.ts) are read-only over business-scope spending; a bill counts if the entry has a receipt or a DocuRepo document linked to it, and GSTIN is read only from linked documents.
- Property/fixed assets (src/lib/assets.ts) live in owner preferences.assets; book SLM/WDV is day-prorated, tax WDV uses block rates with the under-180-day half-rate rule, land never depreciates, and rent checks only read income entries naming the property.
- Income tax/GST working (src/lib/tax-summary.ts) is a read-only per-FY draft from ledger entries and assets; GST input counts only tax printed on business bills, never claimable credit.
- GSTR-2B matching (gstr2b.ts) reads portal JSON on-device only, one-to-one by supplier name word, ±7 days, ₹1/5%; audit-dashboard.ts only aggregates existing read-only rules, so findings clear when records are fixed.
- v6 books (src/lib/books/) are registers around the one ledger, stored in owner preferences.books: Statement Desk routes non-bank documents through DocumentIntake (AI read → pure propose* → one commitIntake write, rolling back the uploaded file on failure); closed periods are enforced by the guard_closed_period trigger on expenses; regulatory rules activate only after approval with dated versions; market prices keep their real freshness label and are never invented or zeroed.
- Approved asset depreciation posts once per asset-month (stable UUID from asset+month) as a non-cash adjustment on the asset's own other_asset/investment account, never a bank account; closed periods and unlinked assets are refused (books/assets-ledger.ts).
- NSE/BSE end-of-day closes come from official bhavcopy files saved by a cron route into shared market_quotes; demat holdings are the canonical copy of a security, so a manual holding with the same ISIN is never added to net worth twice.
- Official rule pages are watched weekly (books/rule-watch.ts): headline fingerprints record detected changes only; rules change solely through owner-approved proposals.
- Filing obligations, ITC review, tax credits and rule impact are pure rules in books/compliance.ts; due dates come from approved `due.<FORM>[.<period>]` register rules over standard defaults, so extensions live in one versioned place and nothing is filed automatically.
- Opening balances (books/fy.ts openingPlan + OpeningBalances.tsx) post dated 1 April `adjustment` entries per linked account via the atomic post_opening_balances RPC with stable entry ids; unbalanced/unlinked lines need a written exception, and undo_opening_balances removes only unedited entries — account opening_balance fields are never rewritten.
- Accountant ITR handoff (books/itr-handoff.ts, ItrHandoff.tsx) is a browser-built ZIP frozen as an evidence-locked DocuRepo document and tracked in books.itrHandoffs; handoffGaps lists only what records cannot supply and never fills a figure.
